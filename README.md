# AI Website Auditor

Paste a URL. Get a website audit back in about 10 seconds: a Health Score,
a performance/accessibility/SEO/best-practices breakdown pulled from real
Google PageSpeed Insights data, a Claude-written summary, and a
severity-ranked list of fixes. Export the report as PDF or CSV.

**🔗 Live:** https://ai-website-auditor-indol.vercel.app

Built and designed end to end by **Mohammed Altounsi** — [LinkedIn](https://www.linkedin.com/in/mohammed-altounsi/)

## The core design decision

The Health Score is never generated by the model. It's `Math.round()` of
the four real PageSpeed Insights scores, computed in code every time the
same site is audited. Claude only writes the summary and the fix list —
anything that has to stay consistent between runs is arithmetic, not an
LLM guess. That split (model explains, code decides) is the pattern this
project exists to demonstrate.

## How it works

1. **`lib/scrape.ts`** — fetches the target page and extracts on-page SEO
   signals (title, meta description, heading count, alt-text coverage,
   canonical tag) with `cheerio`. Includes DNS resolution, IP-range
   blocking, and connection pinning so a user-supplied URL can't be used
   to hit internal/private network addresses (SSRF protection) — the
   auditor accepts an arbitrary public URL, so this had to be solved
   properly rather than skipped.
2. **`lib/pagespeed.ts`** — calls Google's PageSpeed Insights API for the
   four objective scores, then computes the Health Score as their average.
3. **`lib/analyze.ts`** — sends the scrape + PageSpeed data to Claude via
   forced tool-use (`tool_choice: { type: 'tool' }`), so the response is
   always a validated structured object, never free text to parse.
4. **`app/api/audit/route.ts`** — runs the pipeline and returns one JSON
   report.
5. **`app/page.tsx` + `app/components/*`** — URL form, animated Health
   Score gauge, category breakdown, severity-badged fix list, PDF (browser
   print) and CSV export.

## Stack

Next.js (App Router) + TypeScript + Tailwind, Google PageSpeed Insights
API, Anthropic API (`claude-sonnet-5`, forced tool-use), Vitest + Testing
Library.

## Setup

```bash
npm install
cp .env.local.example .env.local
# fill in ANTHROPIC_API_KEY (console.anthropic.com)
# fill in PAGESPEED_API_KEY (console.cloud.google.com — enable "PageSpeed Insights API")
npm run dev
```

## Testing

```bash
npm test
```

## Future improvements

- Swap the mobile-only PSI strategy for a mobile+desktop toggle.
- Rate limit by IP (Vercel KV) once the tool gets real traffic.
