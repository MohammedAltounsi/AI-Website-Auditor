# AI Website Auditor

Paste a URL, get an AI-written site audit in ~10 seconds: a Health Score plus
performance/accessibility/SEO/best-practices breakdown (real PageSpeed
Insights data, not LLM guesswork), a Claude-written summary, and a
severity-ranked list of fixes. Download the report as PDF or CSV.

## Architecture

1. `lib/scrape.ts` — fetches the page HTML and extracts on-page SEO signals
   (title, meta description, heading count, alt-text coverage, canonical tag)
   with `cheerio`.
2. `lib/pagespeed.ts` — calls Google's PageSpeed Insights API for objective
   performance/accessibility/SEO/best-practices scores, then computes a
   deterministic Health Score (average of the four) — the score is never
   generated by the LLM, so the same site scores the same way twice.
3. `lib/analyze.ts` — sends both to Claude via forced tool-use, getting back
   a structured summary + severity-ranked fix list (no free-text parsing).
4. `app/api/audit/route.ts` — runs the three in parallel/sequence and returns
   one JSON report.
5. `app/page.tsx` + `app/components/*` — URL form, hero Health Score, category
   gauges, severity-badged fix list, PDF (browser print) and CSV export.

## Setup

```bash
npm install
cp .env.local.example .env.local
# fill in ANTHROPIC_API_KEY (console.anthropic.com)
# fill in PAGESPEED_API_KEY (console.cloud.google.com — enable "PageSpeed Insights API")
npm run dev
```
